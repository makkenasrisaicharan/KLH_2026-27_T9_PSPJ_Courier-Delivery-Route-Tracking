**Abstract:**
The Courier Delivery Routing and Tracking System is a console-based Java application designed to simplify and manage the process of courier shipment and delivery. It maintains courier details such as tracking ID, sender and receiver information, source, destination, package weight, delivery status, and assigned route. The system allows users to register shipments, update delivery statuses, track packages, and view courier information through a menu-driven interface. Its core functionality includes efficient route management and real-time status tracking, helping users monitor the progress of their deliveries. Built using object-oriented programming principles, collections, methods, and input validation, the application demonstrates modular and structured Java development. The system provides a simple foundation for managing courier operations and can be further extended into a web- or mobile-based delivery management platform with advanced routing and real-time tracking features.
